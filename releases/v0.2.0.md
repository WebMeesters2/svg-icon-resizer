# Release v0.2.0

This release adds a fault-tolerant batch workflow and a local browser viewer
for inspecting original and converted SVG page boundaries side by side.

## Breaking Changes

* None.

## Added

* `convert-all-icons.sh` for converting every `icons/*.svg` file into `icons/square/`.
* Aggregate batch summaries and failure reporting after all inputs have been attempted.
* Dependency-free browser viewer that runs directly from `viewer.html` over `file://`.
* Side-by-side pairing of source and converted SVG files.
* Explicit page boundaries with checkerboard, light, and dark canvas backgrounds.
* SVG `viewBox`, width, height, file-size, missing-output, and square-page inspection.
* Filename filtering, adjustable preview size, buttons, and arrow-key navigation.

## Changed

* Local SVG artwork under `icons/` and `icons/square/` is now excluded from Git.
* The documented batch workflow now uses the repository-provided script.

## Documentation

* Added browser-viewer usage and refresh instructions.
* Documented the batch wrapper, browser assets, validation command, and local-file constraint.

## Dependencies

* No new runtime dependencies.
* The browser viewer uses native browser APIs and requires no web server or build step.

## Validation

* `python3 -m compileall .`
* `python3 -m unittest discover -v` — 8 tests passed.
* `bash -n convert-all-icons.sh`
* `node --check viewer.js`
* End-to-end batch run confirmed that conversion continues after a malformed input and returns an aggregate failure status.
* Git ignore rules verified for both source and converted icon SVGs.
* `git diff --check`

## Upgrade notes

No manual migration is required. Place source files in `icons/`, run
`./convert-all-icons.sh`, and open `viewer.html` to inspect the results.
