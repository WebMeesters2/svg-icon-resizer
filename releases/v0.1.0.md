# Release v0.1.0

Initial release of `svg-icon-resizer`, a lightweight command-line tool that
centers SVG artwork in a configurable, padded square viewport while preserving
the original vector markup and aspect ratio.

## Breaking Changes

* None. This is the first release.

## Added

* Python command-line interface for converting individual SVG icons to square SVGs.
* Configurable padding, minimum visible-height warning, measurement precision, and GraphicsMagick executable.
* GraphicsMagick-based visible-bound measurement without using its SVG writer.
* Gradient-paint compatibility handling for GraphicsMagick measurement.
* Protection against overwriting the input file.
* Bash example for processing multiple icons.
* Automated tests for viewport calculations, SVG rewriting, input validation, and gradient measurement.

## Documentation

* Added installation requirements, command examples, option explanations, and validation commands.
* Added project architecture, local constraints, release workflow, and DOX agent guidance.

## Dependencies

* Requires Python 3.9 or newer.
* Requires GraphicsMagick with SVG reading support.
* The Python implementation uses only the standard library.

## Validation

* `python3 -m compileall .`
* `python3 -m unittest discover -v` — 8 tests passed.
* End-to-end conversion of 15 valid local test SVGs, including gradient-heavy artwork.
* Confirmed that generated viewports are square and artwork remains centered.
* `git diff --check`

## Upgrade notes

No manual migration is required.
